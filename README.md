# 📘 Data Structures – Practicals & Mini Project

Welcome to my **Data Structures** repository! This repository contains practical programs and a mini-project developed as part of my studies.

## 📂 Repository Contents

### 🧪 Practicals
This section contains programs implemented using C to understand and practice different data structures and algorithms, including:

- Arrays
- Searching Algorithms
- Sorting Algorithms
- Singly Linked List
- Singly Circular Linked List
- Stack and Queue
- Trees (BST and AVL)
- Graph Traversal (DFS and BFS)
- Other data structure programs

### 🏥 Mini Project: Hospital Patient Queue System
A C-based mini-project that manages hospital patients according to their priority using a **Priority Queue implemented with a Singly Linked List**.

**Key Features:**
- Add new patients to the queue.
- Assign priority to each patient.
- Serve patients according to priority.
- Display the patient queue.
- Manage patient records using linked list operations.

## 🎯 Purpose

The main purpose of this repository is to practice data structures, understand their implementation, and maintain all practical programs and mini-project work in one place.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the required C program in your preferred code editor.
3. Compile the program using a C compiler.
4. Run the compiled program and test its operations.

Example using GCC:

```bash
gcc filename.c -o output
./output
```

On Windows, run the compiled program using:

```bash
output.exe
```

Replace `filename.c` with the name of the C source file you want to execute.
