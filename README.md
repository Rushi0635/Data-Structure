# Array Operations in C

A simple **Data Structures** practical project implemented in **C** that demonstrates the fundamental operations performed on an array. This project is designed for students to understand how arrays work and how common operations are implemented using C programming.

## 📌 Features

* Array Traversal
* Array Insertion
* Array Deletion
* Array Searching
* User-friendly menu-driven program
* Simple and easy-to-understand code

## 🛠️ Technologies Used

* **Language:** C
* **Compiler:** GCC / Turbo C / Code::Blocks / Visual Studio Code (with GCC)

## 📂 Operations

### 1. Traversal

Displays all the elements stored in the array.

### 2. Insertion

Inserts a new element at a specified position in the array.

### 3. Deletion

Deletes an element from a specified position and shifts the remaining elements.

### 4. Searching

Searches for a given element in the array and displays its position if found.
